## Question

Which donation/fundraising platform (e.g. Stripe, PayPal, Donorbox, Give Lively, Zeffy, Bloomerang, etc.) should The Jentosy Project use? Compare nonprofit pricing/transaction fees, one-time + recurring giving, automated donor receipts/tax acknowledgments, donor data ownership and reporting, mobile-friendliness, ease of integration with a modern (non-Squarespace/Wix) web stack, and ability to scale to institutional/larger-gift inquiries.

## Answer

**Zeffy** is the top recommendation — $0 platform fee and $0 processing fee to the nonprofit (confirmed via Zeffy's own help-center docs), recurring giving, automated IRS-compliant receipts, built-in CRM with CSV export, low-effort embed/API integration for a custom React site. **Give Lively** is a close second (also $0 platform fee, explicit donor-advised-fund support for larger/institutional gifts, brandable custom-site widgets) but passes Stripe/PayPal processing costs through, and its donor-data-ownership terms weren't confirmed in primary sources. Direct **Stripe** (nonprofit rate 2.2%+$0.30) is a viable fallback for full data ownership/UX control, but ships no receipts or CRM out of the box. **Bloomerang** has the strongest CRM/major-gift tracking but at $242/mo is likely premature pre-launch. **PayPal** is recommended only as a secondary payment method within another platform's checkout — PayPal Giving Fund's terms restrict using donor contact info beyond acknowledgment/support. Open items flagged for vendor verification before sign-off: Give Lively's data-ownership terms, Bloomerang's actual processing rates, PayPal's current nonprofit-rate page (404'd during research).
